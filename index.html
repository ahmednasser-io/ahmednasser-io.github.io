Superstore Data Warehouse

PostgreSQL Star Schema, ETL & 16 Analytical Queries
PostgreSQL | SQL

A PostgreSQL data warehouse built on the Superstore retail dataset. Raw order, manager, and returns data is loaded into a staging layer, then transformed into a star schema with one fact table and four dimension tables (customer, product, location, ship mode), enforced with primary and foreign keys and cleaned with DISTINCT ON and COALESCE logic. The project adds indexes on the join and date columns, a denormalized reporting view, and a PL/pgSQL stored procedure for yearly KPIs. Sixteen analytical queries use CTEs and window functions (LAG, RANK, NTILE, running totals) to cover profitability by category and region, discount impact, customer tiers, RFM scoring, month-over-month growth, and return rates, and EXPLAIN ANALYZE is used to verify query performance.

PostgreSQL SQL Star Schema Data Modeling ETL Window Functions CTEs Stored Procedures Indexing RFM Analysis

Baby Photoshop is a desktop image-processing application written in C++, with 18 filters implemented from scratch on raw pixel data. It covers geometric transforms (rotate, flip, crop, resize, skew, merge), tonal adjustments (grayscale, black & white, invert, darken, lighten), spatial filters (blur, edge detection), and creative effects such as infrared, old TV, oil painting, purple tint, and sunlight correction. A reusable variadic-template pipeline loads, filters, and saves each image, which keeps every filter independent and easy to extend, while a Qt GUI puts the whole toolkit behind a clean desktop interface.
